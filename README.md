# Eagle of Cars

Officiële website van Eagle of Cars.

## Lokaal starten

```bash
npm install
npm run dev
```

Open daarna `http://localhost:3000`.

## Publiceren op Vercel

1. Pak het ZIP-bestand uit.
2. Open de repository `eagleofcars-collab/eagle-of-cars` op GitHub.
3. Kies **Add file → Upload files**.
4. Upload de inhoud van deze map, dus `app`, `components`, `public`, `package.json`, enzovoort.
5. Kies **Commit changes**.
6. Ga terug naar Vercel en importeer de repository.
7. Vercel herkent automatisch Next.js. Klik op **Deploy**.
